# Concrete Slump Test dataset attribution

- Original dataset: I-Cheng Yeh, *Concrete Slump Test*, UCI Machine Learning Repository (2007), [DOI:10.24432/C5FG7D](https://doi.org/10.24432/C5FG7D).
- UCI download page: https://archive.ics.uci.edu/dataset/182/concrete+slump+test
- License for this **dataset**: **CC BY 4.0** (separate from the MIT license for the compwaffle code).
- The bundled CSV contains 103 records using the column names supplied with the UCI dataset. The example uses the same seven inputs and three measured outcomes.
- Ingredient columns `Cement`, `Slag`, `Fly ash`, `Water`, `SP`, `Coarse Aggr.`, and `Fine Aggr.` are in **kg per m³ concrete**. The final three columns are measured outcomes, **not ingredients**.
- Please cite the UCI dataset when reusing the data or generated visualizations.
