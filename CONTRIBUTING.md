# Contributing

Issues and pull requests are welcome after the repository is published.

- Use Python 3.10 or newer.
- Install with `python -m pip install -e '.[dev]'`.
- Run `python -m pytest -q` before submitting.
- Preserve scientific meaning: no implicit conversions between percent, mass parts, and volume parts.
- Please include a reproducible test for every geometry or scaling bug.
- The software code is MIT-licensed; the included concrete dataset is separately CC BY 4.0.
